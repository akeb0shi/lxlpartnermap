To access the link to the website (not shown in video). Go to Settings, Then in the "Code and automation" section the last option you will see "Pages". In this page you can see the link to the website and the last time it was updated. Sometimes after pushing the code pages can take up to 5-10 minutes to update the actual site and this page is a useful tool to see if the site has actually updated or not.
